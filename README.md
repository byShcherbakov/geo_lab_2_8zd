# Практическая работа 2 — вариант 2 (N = 7)

Откройте папку `Lab2_VSCode` в VS Code. Программа показывает все задания 1–8 в одном окне. Нажимайте на пункты меню слева или переключайте их пробелом и Backspace (на Mac: Delete ⌫). Кнопка Run Code, которая вызывает `g++ Main.cpp`, для этого проекта не подходит: он состоит из нескольких `.cpp` и библиотек.

## Запуск на Mac

Если зависимости уже установлены:

```bash
cd "/Users/shcherbakov/Downloads/Lab2_VSCode"
bash ./run-macos.sh
```

Если при сборке не хватает библиотек, однократно выполните `brew install cmake glew glfw glm`. После распаковки нового архива убедитесь, что открыта именно новая папка. Каталоги `build-macos` и `build-windows` переносить между ОС не надо.

## Запуск на Windows

Установите [MSYS2](https://www.msys2.org/) в `C:\msys64`. Откройте **MSYS2 UCRT64**, выполните `pacman -Syu` (при запросе перезапустите терминал UCRT64 и повторите), затем:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja mingw-w64-ucrt-x86_64-glew mingw-w64-ucrt-x86_64-glfw mingw-w64-ucrt-x86_64-glm
```

В PowerShell, открытом в папке `Lab2_VSCode`, выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run-windows.ps1
```

## Содержание

| Меню | Что демонстрирует |
|---|---|
| 1 | Семь вершин правильного семиугольника, вычисление в цикле, сглаживание, опыт с размером точки |
| 2 | Семиугольник из семи GL_LINES и изменение толщины кнопками |
| 3 | Первая фигура варианта, открытая GL_LINE_STRIP |
| 4 | Вторая фигура варианта, замкнутая GL_LINE_LOOP |
| 5а | Вторая фигура из отдельных GL_TRIANGLES |
| 5б | Та же фигура из одной GL_TRIANGLE_STRIP |
| 5в | Та же фигура из двух GL_TRIANGLE_FAN, поскольку контур вогнутый |
| 6 | Правильный семиугольник из GL_TRIANGLE_FAN (центр, семь вершин и первая повторно) |
| 7 | Третья фигура, семь отдельных треугольников со случайными цветами |
| 8а | Спереди только вершины, сзади заливка |
| 8б | Спереди заливка, сзади каркас |
| 8в | Спереди и сзади каркас |

Цветные задания автоматически показывают слева плоское тонирование и справа плавное. Можно переключиться на один из видов кнопками наверху. **Плоское:** весь треугольник одного цвета. **Плавное:** цвета вершин интерполируются, получается градиент. Кнопка «Новые цвета» меняет случайные цвета; оба вида сохраняют одни и те же исходные данные для сравнения. В задании 8 слева лицевая сторона, справа отражённая модель (вид сзади).

При запуске на задании 1 автоматически проходит опыт: программа рисует точки нескольких размеров в отдельном кадровом буфере, считывает пиксели и проверяет реальную ширину и полупрозрачные сглаженные края. Результат появляется на экране, в терминале и файле `points_experiment.txt` в папке проекта. Эксперимент можно повторить кнопкой или `E`; `A` переключает сглаживание; стрелки вверх/вниз меняют размер; «Максимум» задаёт предел драйвера. **Впишите в отчёт результат своего Mac**, не значение с другого GPU. В Core profile для сглаживания используется фрагментный шейдер (аналог визуального результата), а не удалённый из профиля `GL_POINT_SMOOTH`. Если аппаратный предел больше размера допустимого тестового кадра, отчёт явно указывает проверенную нижнюю границу.

Клавиши: `Space`/`Backspace` — следующее/предыдущее; `S` — плоское/плавное/сравнение; `L` — толщина линий; `R` — новые цвета; `Esc` — выход. Все операции доступны и через видимые кнопки.

Исходники: `tasks.cpp` — геометрия и примитивы; `Model.cpp` — буферы и режимы рисования; `Demo.cpp` — меню и представление; `Experiment.cpp` — измерение точек; `Ui.cpp`/`FontData.h` — интерфейс; `Main.cpp` — главный цикл; `CMakeLists.txt` — сборка. `FONT_LICENSE.txt` содержит лицензию на шрифт интерфейса.

Проверено: синтаксис всех `.cpp` с `g++ -std=c++17 -Wall -Wextra`; вся сцена собрана и отрисована в тестовом OpenGL 4.5 Core/Mesa: 12 экранов, ноль ошибок OpenGL; опыт с точками подтвердил измерение на тестовом GPU; изображения и разбиение фигур проверены. Сборку непосредственно на macOS/Windows надо выполнить скриптом на соответствующем компьютере.
